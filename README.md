# מצלמים ולומדים (LensLearn)

אפליקציית אנדרואיד ללימוד שפה: מצלמים חפץ, ו-Claude מזהה אותו ומחזיר את שמו בעברית ובשפה הנלמדת, עם תעתיק באותיות לועזיות, הגייה בעברית, השמעה בקול ומשפט דוגמה. כל מילה נשמרת לאוצר מילים בטלפון, ויש מסך תרגול.

- שפות: אנגלית, ספרדית, צרפתית, גרמנית, איטלקית, פורטוגזית, רוסית, ערבית, סינית, יפנית, קוריאנית, הינדית.
- דרוש מפתח API של Anthropic (console.anthropic.com), שמוזן במסך ההגדרות ונשמר רק בטלפון.
- אנדרואיד 10 ומעלה.

כל דחיפה לענף `main` בונה APK חתום אוטומטית (GitHub Actions) ומפרסמת אותו ב-Releases.
