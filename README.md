# זיכרונות – סרטון אוטומטי מתמונות (אנדרואיד)

אפליקציית אנדרואיד מקורית (Kotlin + Jetpack Compose) שהופכת תמונות מהגלריה לסרטון זיכרונות מונפש עם תנועה, מעברים, כותרת ומוזיקה.

## מה היא עושה
- **בחירת עד 40 תמונות** דרך בוחר התמונות של המערכת (בלי הרשאות גישה לאחסון), או "שיתוף" תמונות מהגלריה ישירות לאפליקציה.
- **סידור אוטומטי לפי תאריך הצילום** (EXIF) והצעת כותרת וטווח תאריכים ("יוני – אוגוסט 2026").
- **4 סגנונות**:
  - רגוע: תנועת Ken Burns איטית ומעברי דהייה.
  - אנרגטי: מעברי דחיפה מהירים והבזק על כל חיתוך.
  - וינטג': צבעי ספיה, מסגרת של תמונה מודפסת, גרעיניות וויניֶט.
  - חלומי: תמונה מרחפת, נטייה עדינה ואור חם שנודד על המסך.
  "הפתיעו אותי" בוחר סגנון אקראי.
- **אפקט עומק (פרלקסה)**: תמונה שהצורה שלה שונה מהמסגרת מרחפת ככרטיס מעל עותק מטושטש שלה שזז בכיוון ההפוך.
- **3 גדלים**: סטורי 9:16, ריבוע 1:1, רחב 16:9.
- **תצוגה מקדימה חיה** שמשתמשת בדיוק באותו מנוע ציור של הייצוא.
- **מוזיקה מהטלפון** (MP3/M4A/OGG/WAV): השיר חוזר או נחתך לאורך הסרטון, עם דהייה פנימה והחוצה.
- **אפקט עומק תלת־ממדי בבינה מלאכותית, על המכשיר**: מודל Depth Anything V2 (small) רץ בטלפון עם ONNX Runtime, מזהה מה קרוב ומה רחוק בכל תמונה, והמצלמה זזה בתלת־ממד כך שאנשים ועצמים קרובים זזים יותר מהרקע. חינם ובלי אינטרנט.
- **ייצוא MP4** (H.264 + AAC) ב-1080p או 720p, נשמר בגלריה בתיקייה `Movies/Memories`, עם כפתורי שיתוף וצפייה.
- הכול רץ על המכשיר, בלי שרת ובלי אינטרנט. אין ספריות חיצוניות לווידאו: רק MediaCodec/MediaMuxer של אנדרואיד.

דרישות: אנדרואיד 10 ומעלה (API 29).

## איך מקבלים APK

### הורדה ישירה
בכל עדכון של הקוד GitHub בונה APK חדש ומפרסם אותו ב-Releases. הקישור הקבוע לגרסה האחרונה:
`https://github.com/<user>/<repo>/releases/latest/download/MemoryReel.apk`

### אפשרות 1: Android Studio
1. מתקינים את [Android Studio](https://developer.android.com/studio).
2. מורידים את המודל לתיקייה `app/src/main/assets/depth.onnx`:
   https://huggingface.co/onnx-community/depth-anything-v2-small/resolve/main/onnx/model_quantized.onnx
3. File → Open → בוחרים את התיקייה `MemoryReel`.
3. מחכים לסנכרון של Gradle (בפעם הראשונה זה מוריד את מה שצריך).
4. מחברים טלפון עם "ניפוי באגים ב-USB" מופעל ולוחצים ▶ Run, או Build → Build APK(s).

### אפשרות 2: GitHub, בלי להתקין כלום
1. מעלים את התיקייה לריפו חדש ב-GitHub.
2. הבנייה רצה אוטומטית (קובץ `.github/workflows/build-apk.yml`).
3. ה-APK מתפרסם בלשונית **Releases** בשם `MemoryReel.apk`.
4. מעבירים את ה-APK לטלפון ומתקינים (צריך לאשר "התקנה ממקורות לא ידועים").

> ה-APK חתום במפתח debug כדי שיותקן מיד. לפני העלאה ל-Google Play צריך ליצור מפתח חתימה משלכם.

## מבנה הקוד
| קובץ | תפקיד |
|---|---|
| `SlideshowRenderer.kt` | מצייר כל פריים: תנועת מצלמה, מעברים, סגנונות, כותרת |
| `VideoExporter.kt` | מרנדר את כל הפריימים, ממיר ל-YUV, מקודד H.264 ומאחד עם האודיו |
| `AudioTranscoder.kt` | ממיר את השיר ל-AAC באורך הסרטון, כולל לולאה ודהייה |
| `DepthEstimator.kt` | מריץ את מודל העומק על הטלפון |
| `DepthWarper.kt` | אפקט התלת־ממד: מזיז כל פיקסל לפי העומק שלו |
| `PhotoStore.kt` | טעינת תמונות לפי הצורך, תמונות ממוזערות ועותקים מטושטשים |
| `ReelViewModel.kt` | מצב האפליקציה, מיון לפי תאריך, שמירה בגלריה |
| `ui/AppScreen.kt` | המסכים: מסך פתיחה, עורך, חלון ייצוא |

## רעיונות להמשך
- **הנפשה מלאה בבינה מלאכותית** בסגנון Echoes (אנשים שזזים ומחייכים): דרך API של image-to-video בענן ושרת קטן שמחזיק את המפתח.
- סנכרון חיתוכים לקצב המוזיקה (זיהוי ביטים).
- בחירה אוטומטית של התמונות הטובות מהגלריה (פנים, חדות, כפילויות).
- ספריית שירים מובנית ותבניות נוספות.
