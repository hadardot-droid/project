# טלפרומפטר לאנדרואיד

אפליקציה פשוטה: התסריט גולל בחלק העליון של המסך (קרוב לעדשה) בזמן שהטלפון מצלם וידאו.

## בנייה בלי מחשב (GitHub)
1. צרו מאגר חדש ב-GitHub והעלו אליו את כל הקבצים בתיקייה הזו (כולל התיקייה `.github`).
2. בלשונית **Actions** תרוץ בנייה אוטומטית (כ-3–5 דקות).
3. בלשונית **Releases** יופיע `teleprompter.apk` — הורידו אותו בטלפון והתקינו
   (יש לאשר "התקנה ממקורות לא ידועים").

## בנייה עם Android Studio
פותחים את התיקייה ב-Android Studio ולוחצים Run.

## שימוש
- כותבים/מדביקים תסריט, בוחרים גודל טקסט, מצלמה קדמית/אחורית, ומצב מראה.
- **● הקלט** – ספירה לאחור 3‑2‑1, ואז ההקלטה והגלילה מתחילות יחד.
- נגיעה בטקסט עוצרת/ממשיכה גלילה; אפשר לגרור ידנית.
- הסרטונים נשמרים בגלריה תחת Movies/Teleprompter.

דורש Android 10 ומעלה.
